# TestingFramework


This project is made due to technical assessemt.

This project was written using IntelliJ IDEA Community Edition.

Project Packages
PageObjects:
Contains class files for each web page being tested. Page element definitions / mappings, and functions for interacting with page elements.


# ConfigSettings: 

contains helper functions for reading Framework.properties.
Maven Java Project / Maven Wrapper
This project is written in Java and tests can be executed using Maven commands.

./mvnw clean install
Page Object Model
Page object model is used in this framework, each class contains page element mappings and functions / methods used to interact /verify a specific web page under test.

# Test web page
https://adactinhotelapp.com/index.php     
Accessibility Testing
This project uses axe-selenium package for accessibility testing.


# Selenium WebDriver
This project is configured to use edge WebDriver's. The default is set to edge.
